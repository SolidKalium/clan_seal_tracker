# Destiny Symbols

DestinySymbols.woff2 is the Destiny symbol font distributed by Destiny Item Manager, pinned to commit 891ed7af5c5c42f00bfb475441fe18aa092f151c.

Source: https://github.com/DestinyItemManager/DIM/blob/891ed7af5c5c42f00bfb475441fe18aa092f151c/src/data/font/DestinySymbols.woff2
